# 📚 EducaLink

**EducaLink** é uma plataforma inovadora que visa melhorar a comunicação entre escolas e famílias, proporcionando um ambiente digital eficiente onde pais, responsáveis e professores podem interagir de maneira prática e segura.

## 🚀 Funcionalidades

- **📥 Cadastro de Usuários**
  - Pais e responsáveis podem criar contas para gerenciar informações dos alunos.
  - Professores possuem acesso exclusivo para gerenciar suas turmas.

- **📊 Visualização de Notas**
  - Acesso a notas e avaliações em tempo real.
  - Relatórios de desempenho acadêmico dos alunos.

- **💬 Mensagens**
  - Sistema interno de mensagens entre pais e professores.
  - Notificações sobre eventos e atualizações importantes.

- **🗓️ Calendário Escolar**
  - Visualização de datas como reuniões, feriados e eventos escolares.
  - Gerenciamento de compromissos e atividades escolares.

- **📝 Atividades Pedagógicas**
  - Acompanhamento das tarefas e atividades dos alunos.
  - Recursos de apoio para o desenvolvimento acadêmico.

## 🎯 Objetivos

- **Facilitar a Comunicação:** Canal direto entre pais e professores para troca de informações e feedback.
- **Acompanhar o Desempenho:** Transparência no acompanhamento das notas e progresso dos alunos.
- **Gerenciar Atividades:** Organização do calendário e das atividades pedagógicas.

## 🧑‍💻 Tecnologias Utilizadas

### Frontend
- [React](https://reactjs.org/) — Biblioteca JavaScript para construção de interfaces.
- [TypeScript](https://www.typescriptlang.org/) — Superset do JavaScript com tipagem estática.
- [Vite](https://vitejs.dev/) — Ferramenta de build moderna e rápida.
- [Tailwind CSS](https://tailwindcss.com/) — Framework CSS utilitário e responsivo.
- [shadcn/ui](https://ui.shadcn.dev/) — Conjunto de componentes de UI modernos e acessíveis.
